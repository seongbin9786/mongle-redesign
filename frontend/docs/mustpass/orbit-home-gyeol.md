# mustpass — 궤도 홈과 디자인 시스템 결(Gyeol)

> 왜: UX 방향성 프로토타입 `A-relation-orbit`의 디자인 언어를 앱을 위한 신규 디자인 시스템으로
> 채택하고, 홈(메인)을 그 언어로 개편한다. 토큰 교체만이 아니라 주요 컴포넌트의 형태(버튼 반경·높이,
> 입력 높이, 칩, 탭바)까지 함께 바뀌어야 "적용"이다. 이 표가 깨지면 회귀다.

## 디자인 토큰 계약

- [ ] `src/styles.css`의 `:root`/`.dark`가 결의 램프를 정의한다: 잉크(#26262B 계열) foreground,
      종이(#FFFFFF) card, 표면(#F7F7F8) muted, 결선(#EBEBEC/#DDDDDF) border/input, 따뜻한 강조(#E06A2B).
- [ ] 시그니처 표면은 감정/태그 칩의 per-chip 색을 유지한다(고정 enum로 회귀 금지).
- [ ] elevation 토큰(e1~e4)은 결의 그림자(0 4px 12px rgba(24,24,27,.07) = e1)와 어긋나지 않는다.
- [ ] 다크 모드는 깨지지 않는다(라이트 전용 시안이지만 앱은 다크를 지원하므로 램프를 유지한다).

## 타이포 계약

- [ ] 화면에서 `font-black`/`font-extrabold`(800/900)를 쓰지 않는다. 상한은 600(semibold).
      예외: 브랜드 로고 워드마크(`components/brand/mongle-logo.tsx`)만 허용.
- [ ] `PageTitle`은 600 + 음의 자간(-0.02em) 계약을 유지한다.

## 컴포넌트 형태 계약

- [ ] `Button`은 전 형태 rounded-full(pill)이고, 크기별 높이: xs 28 / sm 32 / default 40 / lg 44 / cta 48.
- [ ] `Input`은 높이 44px(h-11), 반경 12px(rounded-xl), 포커스 시 2px 잉크 링.
- [ ] `Card`는 반경 12px + border + shadow-e1.
- [ ] 탭바 FAB은 48px 잉크 원 + elevation, 탭 라벨은 10px/500.
- [ ] 바텀시트(관계 카드)는 상단 반경 22px, 그랩버 38x4.

## 궤도 홈 계약

- [ ] 홈 헤더는 몽글 로고 + `함께한 순간, / 몽글몽글 쌓이는 중` 문구다. 인원수·정렬 기준 같은
      메타 문구를 헤더에 되살리지 않는다.
- [ ] 홈은 '나' 중심의 궤도 지도가 주연이다. 눈금 7개 = 7일 / 1달(≤31) / 3달(≤92) /
      올해(달력 1월 1일 이후) / 1년(≤365) / 3년(≤1095) / 그 이전(초과 또는 만남 이력 없음).
      위치 자체가 최근성 정보다.
- [ ] '올해'는 달력 기준이라 연초에 '3달'보다 짧아질 수 있다 — `[93, 364]`로 클램프해
      눈금 순서(3달 < 올해 < 1년)가 뒤집히지 않는다.
- [ ] **반경은 경과일의 함수다.** 같은 경과일은 데이터가 뭐든 늘 같은 자리에 앉는다.
      인원수·빈 눈금이 반경을 흔들면 "얼마나 먼가"를 읽을 수 없다(등간격 링 회귀 금지).
- [ ] 구간 두께 = `max(최소 간격, 기간 비례)`. 자리가 있는 구간(1년 이후)은 기간에 비례해
      벌어지고, 그대로 두면 무너질 구간(첫 7일)만 바닥을 깐다. 축 전체를 눌러 담는
      로그·멱함수로 되돌리지 않는다 — 붙어야 할 곳까지 눌린다.
- [ ] 구간 '안'에서는 경과일에 선형이다. 3일과 6일은 정확히 두 배 떨어지고,
      오늘 만난 사람은 `innerRadius`(= '나' 반경 + 노드 반경)에 앉아 '나'에 붙는다.
- [ ] 인원이 몰려 겹치면 구간 하나만 부풀리지 않고 **축 전체를 같은 비율로** 늘린다.
      ('나' 여백은 노드 크기가 정하는 고정값이라 축과 함께 늘어나지 않는다.)
- [ ] 한 구간의 인원이 둘레를 넘으면 한 줄에 밀어 넣지 않고 두께를 나눠 여러 줄로 앉힌다
      (안쪽 줄일수록 최근). 각도에는 id에서 뽑은 고정 흔들림을 줘 얼굴이 목걸이처럼 박히지 않게 한다.
- [ ] 눈금은 인원이 0명이어도 사라지지 않고, 바깥으로 갈수록 옅어진다(선과 라벨의 감쇠 폭은 따로 잡는다).
- [ ] 눈금 배정·구간 계산·각도 분포·이웃 거리·최근 만남 포맷은 `lib/relation-orbit-layout.ts`의
      순수 함수이고 단위 테스트가 있다.
- [ ] 멀어진 관계(intimacy DISTANT 또는 edge.distant)는 숨기지 않고 제 자리에서 옅게(opacity 감쇠) + 점선 quiet arc.
      "흐려진 관계는…" 안내 문구는 두지 않는다(흐림 자체가 표현이다).
- [ ] 인물 노드는 그룹 색(**관계태그 첫 칩** 색)을 파스텔 톤 헤일로 + 아바타 테두리로 나타낸다
      (`lib/relation-tag-colors.ts`의 per-chip 색 단일 출처). 태그가 없으면 색을 꾸며내지 않고 무채색,
      즐겨찾기는 잉크 테두리를 유지한다.
      (혼동 주의: 사람 목록의 ring 색은 **소속**이 정한다 → `people-directory.md`. 홈 궤도는 관계태그 기준이다.)
- [ ] 태그 필터는 서버 필터 대신 클라이언트 흐림(dim)이다 — 숨기지 않고 관계 맥락을 유지한다.
      (PRD §5 "그래프뷰에서 조건에 맞지 않는 사람은 숨긴다"에서 의도 이탈. 프로토타입 A의 정책 채택.)
- [ ] 태그 필터는 **단일 선택**이다(한 번에 칩 하나). 여러 칩을 겹쳐 켜면 지금 무슨 기준으로
      보고 있는지가 흐려져 흐림이 읽히지 않는다. 켜진 칩을 다시 누르면 '전체'로 돌아온다.
- [ ] 홈에는 세로 스크롤이 없다. 지도가 남는 높이를 채우고, 더 보려면 줌(핀치·휠)과 팬으로 본다.
- [ ] 기본 배율은 '사람이 앉아 있는 가장 바깥 눈금'까지를 담되 읽히는 크기(0.72)를 하한으로
      지킨다. 넘치면 화면 밖으로 보내고 '전체 보기'를 상시 띄운다 — 빈 바깥 눈금까지 담으려고
      배율을 낮추면 정작 사람이 다 작아진다.
- [ ] 지도 글자(인물 이름·눈금 라벨)와 선 굵기는 배율의 역수를 곱해 화면상 크기를 유지한다.
      월드와 함께 축소하면 fit 배율에서 6px가 되어 읽히지 않고, 1px 선은 아예 사라진다.
- [ ] 붐빔은 구간 단위가 아니라 **가장 가까운 이웃까지의 화면상 거리**로 잰다(구간이 달라도
      각도가 겹치면 얼굴은 붙는다). 그 값 하나로 이름 표시(≥56px)와 노드 크기(50px 기준,
      최소 58%)를 함께 정하고, 확대하면 같은 배치에서도 이름이 다시 나타난다.
- [ ] 지도를 끌고 온 제스처(팬·핀치)는 노드 클릭으로 이어지지 않는다.

- [ ] 노드 그룹 컬러링: 테두리 색은 첫 관계태그 색이다(per-chip 동적 hex, 고정 enum 회귀 금지).
      대표 색 선정은 `lib/relation-tag-colors.ts` 순수 함수(`primaryTagColor`)이고 단위 테스트가 있다.
      태그가 없으면 무채색 테두리, 즐겨찾기는 잉크 테두리 + 별로 그룹 색보다 우선한다(시안 A의 그룹 표현).
- [ ] 관계태그가 하나도 없으면 필터 줄을 렌더하지 않는다. 필터 결과 0명이면 초기화 방법을 안내한다.
- [ ] 인물 0명 빈 상태: '나' 노드 + 사람 추가 CTA만 남고, 필터·회고 플로팅은 숨긴다(PRD §6 문구 사용).
- [ ] 노드 탭 → 관계 카드 시트(마지막 만남/함께한 기록/알고 지낸 시간 + 기록 남기기/프로필 보기).
      시트에 데이터 출처 없는 섹션(만남 리듬, 감정 분포)을 꾸며내지 않는다.
- [ ] 시트에 이름 밑 요약 줄(`알고 지낸 N · 함께한 기록 M개`)을 되살리지 않는다 —
      바로 아래 3칸이 같은 값을 더 크게 보여준다.
- [ ] 시트에 '조금 조용해진 관계예요' 배너를 되살리지 않는다. 멀어진 관계 표현은 지도의 흐림·점선이 전담한다.
- [ ] `1년 전 오늘` 플로팅 카드(PRD §5)는 홈에서 제거됐다. 카드·쿼리·분석 이벤트를 되살리지 않는다.
- [ ] 설정의 "홈 기본 기간"은 홈의 비노출 기준 필터로 계속 작동한다(화면 토글은 제거).

## 거리감 계약

- [ ] 거리감 표현은 **기울인 평면(tilt, 기본)** 과 **심도(focus)** 두 가지이고, 지도 위 토글로
      바꾸며 `mongle:home-orbit-depth:v1`에 저장된다. 안개·원근 축소 시안은 되살리지 않는다.
- [ ] 기울인 평면에서 **사람은 판에 눕지 않고 서 있다.** 역회전이 '진짜 3D 회전'으로 남으려면
      버튼에 `transform-style: preserve-3d`가 있어야 하고, 3D를 평면화하는 `filter`는
      역회전과 **다른 레이어**에 걸어야 한다. 한 요소에 겹치면 세우기가 세로 찌그러짐이 된다.
      (세우기 / 거리감(filter·opacity·scale) / 부유 애니메이션 = 세 레이어)
- [ ] 붐빔 계산은 기울기를 반영한다 — 판을 눕히면 세로가 `cos θ`만큼 눌리므로 눌린 뒤의
      거리로 이웃을 잰다. 그래야 지평선 쪽에서 이름이 먼저 접힌다.
